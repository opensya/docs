The `create` command initializes a new OpenSya project from a starter template.

It downloads the selected template, configures the project structure, installs dependencies and optionally initializes a Git repository.

::callout{color="primary" icon="i-lucide-rocket"}
`create` is the main entry point for starting a new OpenSya project.
::

## Basic Usage

::code-group

```bash [pnpm]
pnpm create opensya my-app
```

```bash [yarn]
yarn create opensya my-app
```

```bash [npm]
npm create opensya my-app
```

```bash [bun]
bun create opensya my-app
```

::

This creates a new OpenSya application using the default template.

## Interactive Setup

The CLI provides an interactive onboarding experience.

Example:

```txt [CLI]
◆ Welcome to Opensya!

? Where would you like to create your project? ./my-app
? Which package manager would you like to use? pnpm
? Initialize git repository? yes

→ Creating project in my-app
✓ Dependencies installed
✓ Git repository initialized

✨ Opensya project has been created with the default template.
```

## Project Structure

A generated project follows the OpenSya runtime architecture.

```txt [Structure]
my-app/
├── server/
│   ├── controllers/
│   ├── services/
│   ├── database/
│   │   ├── models/
│   │   └── plugins/
│   ├── guards/
│   └── locales/
│
├── client/
│   ├── pages/
│   ├── components/
│   └── plugins/
│
├── .env
└── opensya.config.ts
```

The backend runtime is generated and orchestrated automatically by OpenSya using filesystem conventions.

::code-group

```bash [pnpm]

```

```bash [yarn]
yarn create opensya careers --folder ./apps/careers
```

```bash [npm]
npm create opensya careers -- --folder ./apps/careers
```

```bash [bun]
bun create opensya careers --folder ./apps/careers
```

::

## Skip Dependency Installation

To create a project without installing dependencies:

::code-group

```bash [pnpm]
pnpm create opensya my-app --no-install
```

```bash [yarn]
yarn create opensya my-app --no-install
```

```bash [npm]
npm create opensya my-app -- --no-install
```

```bash [bun]
bun create opensya my-app --no-install
```

::

This is useful for CI workflows or custom installation pipelines.

## Offline Mode

The CLI can use local templates without accessing the remote registry.

```bash [Terminal]
pnpm create opensya my-app --offline
```

Prefer local templates first:

```bash [Terminal]
pnpm create opensya my-app --prefer-offline
```

::callout{color="warning" icon="i-lucide-wifi-off"}
Offline mode requires templates to be available locally.
::

## Shell Mode

Automatically open a shell inside the project directory after creation.

```bash [Terminal]
pnpm create opensya my-app --shell
```

## Template Registry

By default, templates are downloaded from the official OpenSya registry.

```txt [Registry]
https://raw.githubusercontent.com/opensya/templates/main/templates
```

## Next Steps

::code-group

```bash [pnpm]
pnpm run dev
```

```bash [yarn]
yarn dev
```

```bash [npm]
npm run dev
```

```bash [bun]
bun run dev
```

::

Then continue with the runtime documentation to understand how OpenSya orchestrates the backend and frontend runtimes.
