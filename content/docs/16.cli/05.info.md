The `info` command displays useful information about the current OpenSya project and development environment.

It helps debug environments, verify installed versions and inspect runtime tooling.

::callout{color="primary" icon="i-lucide-info"}
The `info` command is useful when reporting issues or debugging runtime environments.
::

## Basic Usage

::code-group

```bash [pnpm]
pnpm opensya info
```

```bash [yarn]
yarn opensya info
```

```bash [npm]
npx opensya info
```

```bash [bun]
bun opensya info
```

::

## Collected Information

The command collects information about:

- Operating system
- CPU
- Node.js / Bun / Deno runtime
- Package manager
- OpenSya CLI version
- OpenSya runtime version
- NestJS version
- Nuxt version

## Runtime Detection

The CLI automatically detects the current JavaScript runtime.

Supported runtimes include:

- Node.js
- Bun
- Deno

Example:

```txt [Runtime Detection]
Node.js version → v22.5.0
```

or:

```txt [Runtime Detection]
Bun version → 1.2.0
```

## Package Manager Detection

The command also detects the current package manager.

Supported package managers include:

- pnpm
- npm
- yarn
- bun

Example:

```txt [Package Manager]
Package manager → pnpm@10.0.0
```

::callout{color="info" icon="i-lucide-package"}
OpenSya automatically detects the active package manager from the current project environment.
::

## Project Version Information

The `info` command reads package metadata directly from the current project.

This includes:

```txt [Versions]
Opensya/cli version
Opensya version
Nest.js version
Nuxt version
```

This helps ensure runtime compatibility between OpenSya and its dependencies.

## Debugging Environments

The `info` command is especially useful when:

- Reporting bugs
- Sharing environment information
- Verifying runtime versions
- Debugging CI environments
- Diagnosing installation problems

Example:

```bash [Terminal]
pnpm opensya info
```

Then include the output when opening a GitHub issue.

## Documentation & Support

The command also provides quick access to:

- Documentation
- GitHub issues
- Discussions

```txt [Resources]
https://opensya.io/docs
https://github.com/opensya/opensya/issues
https://github.com/opensya/opensya/discussions
```

## Philosophy

The `info` command exists to make OpenSya environments easier to inspect and debug.

Instead of manually collecting runtime and dependency information, OpenSya centralizes everything into a single diagnostic command.
